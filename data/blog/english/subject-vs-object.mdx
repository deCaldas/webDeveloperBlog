### Uso de **Who** vs **Whom**

**Quién realiza la acción vs quién la recibe**


##   Objeto gramatical: la persona que recibe la acción

Para dominar el uso de **whom**, primero hay que entender el concepto de **objeto** en una oración.

**En términos simples:**

* **Sujeto (agent):** quien realiza la acción
* **Objeto (recipient):** quien recibe la acción


##   Ejemplo clásico de sujeto y objeto

**Oración:**

> *The student hit the ball.*

* **Sujeto:** *The student* → realiza la acción
* **Objeto:** *The ball* → recibe la acción


##   ¿Qué tiene que ver esto con *whom*?

La palabra **whom** se usa cuando nos referimos al **objeto** (quien recibe la acción), no al sujeto.


##   Caso 1: *Whom* como objeto directo

**Pregunta:**

> *Whom did you invite?*

Aquí, **whom** es la persona que **recibe** la invitación.


##   Caso 2: *Whom* después de una preposición

Las **preposiciones** (*to, with, from, for, etc.*) necesitan un objeto.

**Ejemplo:**

> *To whom did you send the letter?*

**Whom** es el objeto de la preposición **to**.


##   Definición ampliada: preposiciones

Las preposiciones conectan palabras y expresan relaciones como:

* Dirección → *to*
* Compañía → *with*
* Origen → *from*
* Beneficio / motivo → *for*

**Ejemplos:**

* *To whom are you talking?*
* *With whom did you go?*
* *From whom did you receive it?*
* *For whom is this gift?*


##   Regla práctica para decidir

Pregúntate:

* **¿La persona hace la acción?** → usa **who**
* **¿La persona recibe la acción?** → usa **whom**


## 🔎 Explicación adicional para mayor claridad

## 1️⃣ Prueba rápida con *he / him*

Sustituye mentalmente:

* Si encaja **he** → **who**
* Si encaja **him** → **whom**

**Ejemplos:**

* *Who called you?*
  → *He called you* ✅

* *Whom did you call?*
  → *You called him* ✅


## 2️⃣ En inglés moderno (uso real)

En conversación cotidiana:

* **Who** se usa casi siempre, incluso donde sería “correcto” *whom*.

**Informal (común):**
✔ *Who did you invite?*

**Formal / académico:**
✔ *Whom did you invite?*

Ambas se entienden.


## 3️⃣ Cuándo conviene usar *whom*

Especialmente en:

* Escritura formal
* Exámenes
* Contextos académicos
* Después de preposición (muy común en estilo formal)

✔ *To whom it may concern*


## ✅ Resumen esencial

| Función                 | Pronombre |
| ----------------------- | --------- |
| Sujeto (realiza acción) | **Who**   |
| Objeto (recibe acción)  | **Whom**  |
