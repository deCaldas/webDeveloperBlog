# Conjuntions

Las conjunciones en inglés son palabras que se utilizan para conectar palabras, frases o cláusulas en una oración. Aquí tienes una explicación detallada sobre las conjunciones más comunes:

1. **Conjunciones Coordinantes:**

   - **And:** Se utiliza para unir elementos similares. Ejemplo: _I like coffee and tea._
   - **But:** Indica contraste o contradicción. Ejemplo: _I like coffee, but I don't like tea._
   - **Or:** Se utiliza para dar opciones o alternativas. Ejemplo: _Do you want coffee or tea?_

2. **Conjunciones Subordinantes:**

   - **Although/Though:** Introduce una idea que contrasta con la principal. Ejemplo: _Although it's raining, we will go out._
   - **Because:** Indica la razón o causa. Ejemplo: _I stayed indoors because it was raining._
   - **If:** Se utiliza para expresar condiciones. Ejemplo: _If it rains, we'll stay home._
   - **When:** Indica tiempo o momento. Ejemplo: _I will call you when I arrive._

3. **Conjunciones Correlativas:**

   - **Both...and:** Indica inclusión. Ejemplo: _Both John and Mary went to the party._
   - **Either...or:** Expresa opción o alternativa. Ejemplo: _You can either eat now or later._
   - **Neither...nor:** Indica negación de ambas opciones. Ejemplo: _Neither coffee nor tea is my favorite._

4. **Conjunciones de Comparación:**
   - **As...as:** Se utiliza para hacer comparaciones. Ejemplo: _She is as tall as her brother._
   - **Not as...as:** Indica una comparación negativa. Ejemplo: _This book is not as interesting as the other one._

Recuerda que las conjunciones son cruciales para estructurar correctamente las oraciones y transmitir significados precisos.
