Los **comparative adjectives** se usan para **comparar dos personas, objetos o situaciones**.

La estructura más común es:

```
subject + verb + comparative adjective + than + object
```

Ejemplo:

> This beat is **stronger than** the previous one.

Esta guía es una **lista de referencia de adjetivos cortos** que forman el comparativo con **-er**.


## Reglas ortográficas

Al añadir **-er**, algunos adjetivos cambian ligeramente su forma.

### 1. Adjetivos que terminan en **-y**

Cuando un adjetivo termina en **consonante + y**, la **y cambia a i**.

```
consonant + y → ier
```

Ejemplos:

| Adjective | Comparative |
|-----------|-------------|
| easy | easier |
| happy | happier |
| busy | busier |
| heavy | heavier |
| funny | funnier |
| lucky | luckier |



### 2. Adjetivos que terminan en **-e**

Si el adjetivo termina en **e**, solo se añade **-r**.

```
adjective + r
```

Ejemplos:

| Adjective | Comparative |
|-----------|-------------|
| nice | nicer |
| large | larger |
| brave | braver |
| rude | ruder |
| safe | safer |
| wide | wider |



### 3. Patrón **consonante-vocal-consonante (CVC)**

Cuando el adjetivo termina en **consonante + vocal + consonante**, se **duplica la última consonante**.

```
CVC → double consonant + er
```

Ejemplos:

| Adjective | Comparative |
|-----------|-------------|
| big | bigger |
| hot | hotter |
| sad | sadder |
| thin | thinner |
| fat | fatter |
| wet | wetter |


## Comparative adjectives with -er (reference list)


| ugly | uglier |

| unlucky | unluckier |
| warm | warmer |
| weak | weaker |
| wide | wider |
| young | younger |


## Comparativos irregulares

Algunos adjetivos cortos **no siguen la regla de -er**.

| Adjective | Comparative |
|-----------|-------------|
| good | better |
| bad | worse |
| far | farther / further |



## Nota sobre **than**
