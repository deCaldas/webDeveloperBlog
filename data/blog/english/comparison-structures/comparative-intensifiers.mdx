La estructura **Comparative Intensifiers** se usa para **modificar la fuerza del comparativo**.

## Comparative Intensifiers

Un **intensifier** es una palabra que aumenta o reduce el grado del comparativo.

Estructura general:

```
intensifier + comparative adjective
```

Ejemplos:

* This beat is **much stronger** than the previous one.
* This exercise is **slightly easier** than the last one.

## Intensifiers más comunes

### Intensificadores fuertes

Expresan **gran diferencia**.

| Intensifier | Example            |
| ----------- | ------------------ |
| much        | much better        |
| far         | far more difficult |
| a lot       | a lot easier       |
| way         | way stronger       |

Ejemplos:

* This problem is **much harder than** the previous one.
* This road is **far longer than** I expected.
* This verse is **way better than** the last one.

### Intensificadores moderados

Expresan **diferencia pequeña o gradual**.

| Intensifier | Example         |
| ----------- | --------------- |
| slightly    | slightly better |
| a little    | a little faster |
| a bit       | a bit easier    |

Ejemplos:

* Staying up late is **slightly easier than** going to bed early.
* The room is **a little warmer than** yesterday.

### Posición en la estructura

El intensificador siempre aparece **antes del comparativo**.

Patrón:

```
subject + verb + intensifier + comparative + than
```

Ejemplo:

> This version is **much better than** the previous one.

## Resumen

| Structure                         | Function           |
| --------------------------------- | ------------------ |
| much / far / way + comparative    | gran diferencia    |
| a little / slightly + comparative | pequeña diferencia |
