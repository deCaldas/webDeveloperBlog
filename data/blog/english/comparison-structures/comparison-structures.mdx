## Familias gramaticales

### 1. Comparison structures

Estas estructuras comparan **cantidad, grado o diferencia** entre cosas.

#### 1.1 [Comparative adjectives](./comparative-adjectives)

Comparan **dos elementos**.

**Patrones**

* **adjective + -er + than**
* **more / less + adjective + than**

Ejemplos:

* This road is **longer than** the other one.
* This exercise is **more difficult than** the previous one.


#### 1.2 [Superlative adjectives](./superlative-adjectives)

Indican **el grado máximo dentro de un grupo**.

**Patrones**

* **the + adjective + -est**
* **the most / the least + adjective**

Ejemplos:

* This is **the longest** river.
* She is **the most talented** singer in the group.


#### 1.3 [Equality](./equality)

Expresa **igualdad o diferencia de grado**.

**Patrones**

* **as + adjective + as**
* **not as / not so + adjective + as**

Ejemplos:

* This beat is **as strong as** the previous one.
* This road is **not as long as** I expected.

#### 1.4 [Comparative intensifiers](./comparative-intensifiers)

Se usan para **modificar la fuerza del comparativo**.

**Patrones**

* **intensifier + comparative adjective**

Ejemplos:

* This beat is **much stronger than** the previous one.
* This exercise is **slightly easier than** the last one.


### 2. Comparative change structures

Estas estructuras describen **cambios o tendencias**.

#### 2.1 [Repeated comparatives](./repeated-comparatives)

Expresan **cambio gradual**.

**Patrón**

```
comparative + and + comparative
```

Ejemplos:

* The beat is getting **stronger and stronger**.
* The night became **colder and colder**.


#### 2.2 [Parallel change](./parallel-change)

Expresa **relación entre dos cambios**.

**Patrón**

```
the + comparative…, the + comparative
```

Ejemplos:

* **The more** I practice, **the better** I rap.
* **The harder** you work, **the stronger** you become.


### 3. [Cause and result structures](./cause-effect)

Estas estructuras conectan **causa y consecuencia**.

#### 3.1 So … that

Se usa con **adjetivos o adverbios**.

**Patrón**

```
so + adjective + that
```

Ejemplo:

* The beat was **so loud that** everyone stopped talking.


#### 3.2 Such … that

Se usa con **sustantivos**.

**Patrón**

```
such + noun + that
```

Ejemplo:

* It was **such a powerful song that** the crowd went silent.


## Vista general del sistema

| Category                 | Structure                   | Function           |
| ------------------------ | --------------------------- | ------------------ |
| Comparative              | -er / more + than           | compare two things |
| Superlative              | -est / the most             | highest degree     |
| Equality                 | as…as                       | equal degree       |
| Comparative intensifiers | intensifier + comparative   | modify degree      |
| Repeated comparatives    | comparative and comparative | gradual change     |
| Parallel change          | the + comparative           | related change     |
| Cause & result           | so / such + that            | consequence        |


### Observación importante

Los tres primeros temas (**comparatives, superlatives, equality**) forman el **núcleo del sistema de comparación** en inglés.

Los otros (**repeated comparatives, parallel change, so/such**) son **extensiones semánticas** que expresan:

* **cambio**
* **relación**
* **resultado**
