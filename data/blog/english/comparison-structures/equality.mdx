# 🎯 **“as … as”**

## Se usa para **comparar igualdad**.

### 1️⃣ Con **adjetivos**

**as + adjective + as**

* ✔ **I am as strong as yesterday.**
* ✔ My life is **as hard as** yours
* ✔ She is **as strong as** him

### 2️⃣ Con **adverbios**

**as + adverb + as**

* ✔ I run **as fast as** you
* ✔ **I run as fast as I can.**
* ✔ She learns **as quickly as** me
* ✔ **She learns as quickly as you.**

### 3️⃣ Forma **Negativa (desigualdad)**

**not as + adjective/adverb + as**

* ✔ This test is **not as difficult as** the last one
* ✔ I don’t run **as fast as** before
* ✔ **This moment is not as easy as I expected.**

## 4️⃣ **Con cantidad**

| Estructura     | Uso         |
| -------------- | ----------- |
| **as much as** | incontables |
| **as many as** | contables   |

* ✔ **I don’t have as much time as before.**
* ✔ **I don’t have as many opportunities as others.**

El uso de *as…as* ** depende de:

* ✅ Exposición
* ✅ Repetición
* ✅ Uso activo

Es una estructura **mecánica**.

## 🚀 Cómo aprender a usar **as … as**

### ✅ 1. Memoriza la fórmula

```
as + adjective/adverb + as
not as + adjective/adverb + as
```

### ✅ 2. Practica con plantillas

**Adjetivos:**

* I am as ______ as you
* This is not as ______ as before

**Adverbios:**

* I run as ______ as he does
* She speaks as ______ as her sister

### ✅ 3. Conecta con tu vida (mejor retención)

* ✔ My pain is as deep as the ocean
* ✔ I fight as hard as I can
* ✔ The beat hits as strong as thunder

### ✅ 4. Haz contrastes

* ✔ Comparatives: *stronger than*
* ✔ Equality: *as strong as*

* He is **stronger than** me
* He is **as strong as** me

### ✅ 5. Micro-drill (entrenamiento rápido)

Completa mentalmente:

1. Today is as ______ as yesterday
2. I’m not as ______ as before
3. I move as ______ as I can
4. My life is as ______ as yours.
5. This road is not as ______ as it seems.
6. I will run as ______ as I can.
7. I don’t have as much ______ as before.

### ✅ 6. Aplicado

#### 📝 Ejemplos estilo lírica

- ✔ **My memories are as heavy as stones.**
- ✔ **Hope is as fragile as glass.**
- ✔ **This journey is as difficult as I imagined.**
- ✔ **I try to stay as calm as possible.**
- ✔ **I’m fighting storms as dark as night**
- ✔ **Carrying pain as deep as the sea**
- ✔ **Dreams as big as my fears**

## ⚠️ Errores típicos

- 🚫 *as more as*
- 🚫 *as difficult than*
- 🚫 *so hard as* (en afirmativa suena anticuado)
- 🚫 *as better as*
