### 1. Idea central

En inglés, **muchos verbos no funcionan solos**.
Exigen una **preposición fija** para poder conectarse con su complemento.

> La preposición **no se elige**:
> **el verbo la impone**.

Si usas otra preposición (o ninguna), la frase queda incorrecta aunque el significado “se entienda”.

---

### 2. Qué es un verbo con preposición obligatoria

Es un verbo que **no admite objeto directo** y necesita una preposición específica para completar su significado.

**Estructura general:**

```
verbo + preposición obligatoria + objeto
```

Ejemplo:

* ❌ *depend you*
* ✅ *depend **on** you*

---

### 3. Algunos verbos (clasificados por preposición)

#### A) Verbos que requieren **ON**

| Verbo       | Estructura         | Ejemplo                           |
| ----------- | ------------------ | --------------------------------- |
| depend      | depend **on**      | Success depends **on** discipline |
| rely        | rely **on**        | I rely **on** my instincts        |
| focus       | focus **on**       | Focus **on** your goals           |
| concentrate | concentrate **on** | Concentrate **on** your breath    |
| agree       | agree **on**       | We agreed **on** the plan         |

---

#### B) Verbos que requieren **TO**

| Verbo      | Estructura                  | Ejemplo                           |
| ---------- | --------------------------- | --------------------------------- |
| belong     | belong **to**               | I belong **to** no system         |
| contribute | contribute **to**           | This contributes **to** my growth |
| lead       | lead **to**                 | This led **to** change            |
| apply      | apply **to** (institutions) | I applied **to** the program      |
| react      | react **to**                | He reacted **to** the news        |

---

#### C) Verbos que requieren **FOR**

| Verbo | Estructura           | Ejemplo                       |
| ----- | -------------------- | ----------------------------- |
| look  | look **for**         | I’m looking **for** the truth |
| wait  | wait **for**         | Wait **for** me               |
| ask   | ask **for**          | Ask **for** help              |
| apply | apply **for** (jobs) | I applied **for** the job     |

---

#### D) Verbos que requieren **ABOUT**

| Verbo    | Estructura         | Ejemplo                          |
| -------- | ------------------ | -------------------------------- |
| complain | complain **about** | Don’t complain **about** pain    |
| worry    | worry **about**    | Don’t worry **about** tomorrow   |
| talk     | talk **about**     | We talked **about** the issue    |
| think    | think **about**    | I’m thinking **about** my future |

---

#### E) Verbos que requieren **IN / FROM**

| Verbo   | Estructura     | Ejemplo                     |
| ------- | -------------- | --------------------------- |
| believe | believe **in** | I believe **in** discipline |
| learn   | learn **from** | I learned **from** failure  |

---

### 4. Errores típicos del hispanohablante

| Error                 | Corrección                  | Motivo               |
| --------------------- | --------------------------- | -------------------- |
| *concentrate in*      | concentrate **on**          | Preposición fija     |
| *complained* con *do* | don’t **complain**          | Verbo base tras *do* |
| *lead* mal conjugado  | leads / led **to**          | Tiempo verbal        |
| *looking for wallet*  | looking for **my/a** wallet | Artículo obligatorio |
| *apply for a program* | apply **to** a program      | Uso correcto         |

---

### 5. Caso especial: **apply to vs apply for**

| Uso                       | Preposición | Ejemplo                   |
| ------------------------- | ----------- | ------------------------- |
| Instituciones / programas | **to**      | apply **to** a university |
| Trabajos / cargos         | **for**     | apply **for** a job       |

Ambas formas son correctas, pero **no intercambiables**.

---

### 6. Regla práctica para estudiar (clave)

❌ No memorices el verbo solo
✅ Memoriza el **bloque completo**

Ejemplo correcto:

* depend **on**
* complain **about**
* concentrate **on**
* apply **for / to**

---

### 7. Conclusión

* Las preposiciones **no se traducen**.
* El verbo **manda la estructura**.
* La corrección se logra por **repetición y uso real**.
* Cuando el bloque se automatiza, el error desaparece.
