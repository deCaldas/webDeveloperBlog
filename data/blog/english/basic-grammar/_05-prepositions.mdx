# Prepositions

Las preposiciones son palabras que indican la relación entre dos elementos en una oración. Aquí tienes una guía completa sobre las preposiciones en inglés:

**1. In, On, At:**

- **In:** Se usa para períodos de tiempo más largos (in the morning, in September) y lugares cerrados o grandes regiones (in the city).
- **On:** Se utiliza para días específicos (on Monday) y superficies planas (on the table).
- **At:** Se emplea para momentos específicos (at 3 o'clock) y ubicaciones precisas (at the park).

**2. By, With:**

- **By:** Indica el método o medio (by car, by train) y también se utiliza para referirse a un tiempo límite (by tomorrow).
- **With:** Se refiere a estar en compañía de alguien o algo (with friends, with a book).

**3. For, Since:**

- **For:** Se utiliza para expresar la duración de tiempo (for two hours, for a week).
- **Since:** Indica el inicio de una acción en el pasado y se usa con tiempos verbales perfectos (since yesterday, since I came).

**4. From, To, Into:**

- **From:** Indica el punto de origen (from the airport, from Monday to Friday).
- **To:** Se utiliza para expresar movimiento hacia un lugar o límite de tiempo (to the store, from 9 to 5).
- **Into:** Implica movimiento hacia el interior (into the house).

**5. Between, Among:**

- **Between:** Se emplea cuando se compara o distingue dos elementos (between two cities).
- **Among:** Se utiliza cuando se compara o distingue entre más de dos elementos (among the students).

**6. Under, Over, Above, Below:**

- **Under:** Indica posición por debajo de algo (under the table).
- **Over:** Se utiliza para indicar movimiento sobre una posición (over the bridge).
- **Above:** Similar a "over", indica posición superior (above the clouds).
- **Below:** Indica posición por debajo de algo (below sea level).

**7. Behind, In front of, Beside:**

- **Behind:** Se refiere a la posición posterior (behind the house).
- **In front of:** Indica posición frontal (in front of the building).
- **Beside:** Significa al lado de (beside the river).

Estos son solo algunos ejemplos, pero hay muchas más preposiciones en inglés. La práctica constante te ayudará a familiarizarte con su uso.
